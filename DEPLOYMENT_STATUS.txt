1. DEPLOYMENT ARCHITECTURE
--------------------------------------------------------------------------------
UniGuard AI supports two proven cloud production architectures:

[Architecture A: Unified Full-Stack Cloud Service (Render / Railway / Docker)]
- Service: Render Web Service (or Docker Container on Fly.io/Cloud Run)
- Mechanism: FastAPI backend binds to 0.0.0.0:$PORT, serves the pre-compiled
  React Single Page Application from frontend/dist/ at root '/', handles all
  client-side SPA routing via catch-all, serves REST APIs at /api/*, and serves
  the real-time alert feed at /ws/alerts (wss:// in HTTPS).
- Advantage: Zero cross-origin latency, no CORS synchronization issues, single
  unified HTTPS link for evaluators, zero configuration required.

[Architecture B: Decoupled Multi-Cloud Architecture (Vercel + Render)]
- Frontend Service: Vercel (React 18 + Vite + Tailwind CSS)
  - Root: frontend/ or repository root
  - Rewrites: /(.*) -> /index.html
  - Environment Variable: VITE_API_BASE_URL=https://<render-backend>.onrender.com
- Backend Service: Render Web Service (FastAPI + Uvicorn)
  - Runtime: Python 3.11+
  - Build Command: pip install -r backend/requirements.txt
  - Start Command: uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT
  - Environment Variable: ALLOWED_ORIGINS=https://<vercel-app>.vercel.app
- WebSocket: Frontend automatically derives wss://<render-backend>.onrender.com/ws/alerts
