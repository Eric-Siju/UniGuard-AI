# UniGuard AI Architecture Documentation

## Problem Statement SIH26145
**"AI-Based Detection of Cyber Threats in Unidirectional IP Traffic"**

Unidirectional IP traffic occurs in highly secure, isolated, or air-gapped environments such as:
1. **Critical Infrastructure (OT / SCADA):** Power grids, nuclear facilities, water treatment plants.
2. **Classified Defense Networks:** Forward-operating intelligence links where information flows one-way into an analysis enclave.
3. **Hardware Optical Data Diodes:** Physical fiber links where the transmit laser on the receiver side is physically severed.

### The Unidirectional Challenge
Standard network intrusion detection systems (Snort, Suricata, Zeek, Bro) rely heavily on bidirectional flow reconstruction:
- Inspecting SYN -> SYN-ACK -> ACK handshakes
- Calculating round-trip time (RTT)
- Correlating client requests with server HTTP status codes / RST teardowns
- Active network probing (Nmap sweeps, banner grabbing)
- Dynamic TCP RST packet injection or inline drop

In **unidirectional monitoring**, the monitoring system sees traffic flowing in one direction only. The observer **must never transmit any packet back into the monitored network**. The system operates as a purely passive listener.

## Core Components Breakdown

### 1. Passive Ingestion Layer (`backend/app/engine/parser.py`)
- **Scapy PCAP Dissection:** Reads Layer 2/3/4 headers. Extracts IP 5-tuple, packet size, inter-arrival timestamp, and TCP flags. Passively scans for TLS ClientHello SNI headers and DNS Question Name without decrypting or handshaking.
- **CSV Schema Normalizer:** Accepts heterogeneous flow records from public datasets (CIC-IDS, TON_IoT, NetFlow, Zeek) and normalizes alias columns (`srcaddr`, `sport`, `TotBytes`, `dur`) into canonical UniGuard fields.

### 2. Unidirectional Flow Aggregator (`backend/app/engine/flow_aggregator.py`)
- Groups packet observations into forward sessions by `(src_ip, dst_ip, src_port, dst_port, protocol)`.
- Calculates statistical moments:
  $$\text{Mean IAT} = \frac{1}{N-1} \sum_{i=1}^{N-1} (t_{i+1} - t_i)$$
  $$\text{IAT Std Dev} = \sqrt{\frac{1}{N-1} \sum (t_{i+1} - t_i - \mu)^2}$$

### 3. Feature Extractor (`backend/app/engine/feature_extractor.py`)
Generates a 26-dimensional mathematical representation:
- **Flow Velocity:** `packets_per_sec`, `bytes_per_sec`, `avg_packet_size`, `packet_size_std`.
- **Topological Diversity:** Sliding-window context tracker computes `fan_in` (destination convergence), `fan_out` (host dispersion), `unique_dst_ports`, and `conn_frequency`.
- **Entropy:** Computes Shannon entropy on DNS domain strings and TLS SNI:
  $$H(X) = -\sum_{i=1}^n P(x_i) \log_2 P(x_i)$$
- **Exfiltration Asymmetry:** `outbound_bytes` and `outbound_ratio`.

### 4. Detection Engines
- **Multi-Signal Rule Engine (`rules.py`):** Encodes expert SOC heuristics across all 6 threat classes requiring multi-factor confirmation before alerting.
- **Random Forest Classifier (`ml_detector.py`):** 100 decision trees trained with stratified 70/30 holdout.
- **Isolation Forest (`ml_detector.py`):** Evaluates anomaly distance in feature space for zero-day outliers.
- **Explainable AI (XAI):** Weights z-score feature deviations by Gini impurity feature importance to explain exactly *why* a classification was made.
